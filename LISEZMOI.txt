VITALSCOPE — deux gestes
========================

1. SUR GITHUB (github.com/alex5422/longevis) : remplacer streamlit_app.py
   par celui de ce dossier (Add file → Upload files, puis Commit).
   Streamlit redéploie tout seul en une à deux minutes.

2. SUR STREAMLIT CLOUD (share.streamlit.io) : votre application → ⋮ →
   Settings → Secrets, coller ces deux lignes, puis Save :

     VITALSCOPE_IDENTIFIANT = "vitalscope"
     VITALSCOPE_MOT_DE_PASSE = "VitalScope-2026"

   Tant que ces lignes ne sont pas collées, l'accès reste libre :
   un oubli ne casse rien.

Ce qui change :
- un écran d'accès réservé aux testeurs, comme les quatre autres ;
- « Upload » et « 400MB per file » passent en français ;
- la phrase « Une seule vidéo suffit pour les sept tests », trompeuse,
  explique désormais qu'il faut ouvrir l'onglet du geste filmé ;
- l'intitulé de l'âge dit enfin que 0 signifie « comparaison aux adultes » ;
- les cinq cases « à venir » sont masquées (conservées dans le code).
