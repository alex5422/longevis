# LongeVis — projection volumétrique de la marche

Une séquence vidéo suffit à mesurer la vitesse de marche, la cadence,
l'amplitude du pas et le coût des demi-tours.

**Outil de recherche — pas un dispositif médical.** Aucun diagnostic, aucune
prédiction d'espérance de vie. Les séquences envoyées ne sont jamais conservées.
